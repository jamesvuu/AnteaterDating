# AnteaterDating

A UCI-focused adaptation of the BruinDating student matching application.

## Status
Work in progress. Not deployed or verified for production use. The original project includes integration gaps in OAuth callback handling and chat message submission.

## Stack
Next.js, TypeScript, Django REST Framework, PostgreSQL, Google OAuth, JWT, and Django Channels.

## Setup
See [docs/setup.md](docs/setup.md) after the source migration. Configure a local PostgreSQL database, Google OAuth credentials, and environment variables. Never commit credentials.
